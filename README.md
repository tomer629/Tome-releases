# Tome

Tome: one big book for your life's work. A new tab page for Chrome and Edge with a Kanban board, linked Notes, calendar, reminders, weather and themes.

## Download

Get **Tome.zip** from the newest release: [Releases](../../releases/latest).

## Install (about 5 minutes)

### Windows (Chrome or Edge)

1. Right-click **Tome.zip** and choose **Extract All**.
2. Click **Browse**, pick your **Documents** folder, then click **Extract**. Leave the Tome folder there: Tome runs from it, so moving or deleting it removes Tome.
3. Type `chrome://extensions` (Chrome) or `edge://extensions` (Edge) in the address bar and press Enter.
4. Turn on **Developer mode** (Chrome: top right; Edge: on the left).
5. Click **Load unpacked**.
6. Go to **Documents**, click the **Tome** folder once, then click **Select Folder**.
7. Open a new tab (Ctrl+T). Tome appears, and its Help opens in a second tab. If the browser asks whether to keep the new tab page change, keep it.

### Mac (Chrome)

1. In Finder, double-click **Tome.zip**. Drag the new **Tome** folder into **Documents**.
2. Type `chrome://extensions` in the address bar and press Enter.
3. Turn on **Developer mode** (top right), then click **Load unpacked**.
4. Go to **Documents**, click the **Tome** folder once, then click **Select**.
5. Open a new tab (Cmd+T).

### Then

Read the Help tab and set up a backup folder (Help, **Saving and backups**). Until you do, your data is only in the browser.

## Updating

Download the new Tome.zip, extract it, and copy its files over the ones in your existing Tome folder (keep the same folder, or your data won't follow). Tome shows a blue **Reload Tome** bar within a minute: click it.

## If something goes wrong

| Problem | Fix |
| --- | --- |
| No Load unpacked button | Turn on Developer mode. On a work computer it may be blocked: ask your IT team. |
| "Manifest file is missing" | Wrong folder. Pick the Tome folder that has **manifest.json** inside. |
| New tab isn't Tome | On the extensions page, make sure Tome is switched on. Open a new tab and keep the change. |

If the browser later warns about extensions in developer mode, just close the message. Don't turn them off.
